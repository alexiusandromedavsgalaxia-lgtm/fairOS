# FairOS

Arch Linux based x86_64 desktop OS for UTM

Targets: GNOME 50, 1280 MiB RAM, 30 GiB minimum disk, UEFI, pacman/.arch, dpkg/.deb, .fair wrapper, PipeWire, NetworkManager, QEMU tools and zram

Build with ./scripts/build-iso.sh or GitHub Actions

UTM: x86_64, q35, UEFI, 1280 MiB RAM, 2 CPU, virtio graphics, 30 GiB disk
